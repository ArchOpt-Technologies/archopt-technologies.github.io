VALIDATION REPORT

EnergyFront and ASHRAE Standard 140

Report version 1.0 · 20 October 2026 · EnergyFront 3.5 · EnergyPlus 9.4.0 · ArchOpt Technologies
Download this report (PDF) EnergyFront

Summary. EnergyFront rebuilt the building envelope test cases 600, 900, 600FF and 900FF of ANSI/ASHRAE Standard 140 and reproduced the results of the reference EnergyPlus models within 0.02 % for annual and peak loads and within 0.01 K for free-floating temperatures. 12 of 14 results lie within the range of the example results of the standard; the remaining two, the annual and peak sensible cooling of case 600, lie about 2 % above that range, and the reference model run directly in EnergyPlus gives the same values.

1. Purpose

EnergyFront writes the EnergyPlus input file (IDF) from the inputs of its interface; EnergyPlus performs the simulation. The simulation engine itself is tested by its developers with Standard 140. This report tests the part EnergyFront adds: that the model it generates from its own inputs is the model the user describes, and that it gives the same results as an independently written reference model.

2. Test cases

The cases are the basic building thermal envelope and fabric load tests of ANSI/ASHRAE Standard 140. All four use one single-zone building with south-facing windows, a constant internal gain, constant infiltration and the Denver weather file of the standard.

3. Method

  1. Reference models. Case 600 is case_en_600.idf of NREL BESTEST-GSR (integration testing), with the version set to 9.4 and 6 time steps per hour. Case 900 uses the heavyweight wall and floor constructions (HWWALL, HWFLOOR) of the BESTEST-GSR construction sets. The free-floating cases are the same models without the thermostat and the ideal loads.
  2. EnergyFront models. Each reference IDF was opened in EnergyFront with File > Open IDF 9.4, which converts it into an EnergyFront project. EnergyFront then generated a new IDF from that project.
  3. Simulation. Both IDFs were run with EnergyPlus 9.4.0 and the weather file 725650TYCST.epw (Denver) of Standard 140-2020.
  4. Results. Annual loads are the sum of the hourly Zone Air System Sensible Heating Energy and Zone Air System Sensible Cooling Energy; peaks are the largest hourly values. Free-floating results use the hourly Zone Mean Air Temperature.
  5. Comparison. EnergyFront was compared with the reference model (code-to-code) and with the range of the example results of the standard (RESULTS5-2A, informative Annex B8). The example results are not acceptance criteria.

6. Discussion

EnergyFront reproduces the reference model in every case: the largest difference is 0.02 % for loads and below 0.01 K for temperatures, which is within the rounding of the outputs. This shows that the inputs EnergyFront holds (geometry, layered constructions, glazing defined layer by layer, internal gains with their radiant fraction, infiltration, thermostat and ideal loads) are written to the IDF without loss.

The annual sensible cooling and the peak sensible cooling of case 600 lie about 2 % above the range of the example results. The reference IDF run directly in EnergyPlus 9.4 gives the same values, so the difference belongs to the reference model and the EnergyPlus version, not to the model EnergyFront writes. Annex B8 of the standard states that the example results are informative and are not acceptance criteria.

As an additional check, the case 600 model of the 2011 edition of the standard (prepared by GARD Analytics, with a raised floor exposed to outdoor air) gave the same heating and cooling loads in EnergyFront as the original IDF within 0.01 %, both with the Denver weather file and with an Abu Dhabi weather file.

7. Scope and limitations

  • This is an inter-model (code-to-code) comparison and a comparison with the example results of the standard. It is not an empirical validation against measured data.
  • The tests cover the building thermal envelope with ideal loads. They do not cover the HVAC system templates, natural ventilation, the AirflowNetwork model, daylighting controls, shading devices other than those of the test cases, or multi-zone buildings, which are not part of these cases.
  • The results apply to EnergyFront 3.5 with EnergyPlus 9.4.0. Other versions, and models with other inputs, may give different results.
  • Standard 140 is a method of test, not a certification. This report does not state that EnergyFront is certified or approved by ASHRAE.
