1. What EnergyFront does and what was tested

EnergyFront does not compute building physics itself. It writes an EnergyPlus input file (IDF) from the inputs of its interface, runs EnergyPlus 9.4 and reads back the results. The tests therefore answer three questions: (1) does EnergyFront write the same model as a reference IDF, so that EnergyPlus gives the same results; (2) when an existing IDF is opened in EnergyFront, what is kept, what is approximated and what is lost, and is every loss reported to the user; (3) do the inputs of the interface reach the IDF as intended. The accuracy of the physics itself is that of EnergyPlus 9.4 and is documented by its developers.

  • Method A, generation fidelity: ASHRAE Standard 140-2020 envelope cases entered in EnergyFront; the EnergyFront IDF and the reference IDF run with the same weather file and compared.
  • Method B, round trip of an IDF: HVAC BESTEST, Furnace BESTEST and EnergyPlus 9.4 example files opened with File > Open IDF 9.4, written again by EnergyFront and run.
  • Method C, software tests: automated tests of inputs, rules, units, interface, tagging for PareVia and EPCalibration, and traceability of every input to the IDF objects it changes.

5. Automated software tests (Method C)

  • Inputs and rules: 170 checks passed. Units and generator: 514 checks passed. Interface: 488 checks passed. Tagged IDF and CSV for PareVia and EPCalibration: 47 checks passed.
  • Traceability: 307 inputs in 30 buildings; each change must change the IDF objects listed in the traceability matrix.
  • Verification report: one known open item (ground temperature of an imported layered construction).
  • Every run of EnergyFront writes a verification report (Results > Verification) that lists the inputs next to what EnergyPlus reports back. It is a check of each model, not of the tool in general.

6. Known limitations (summary)

The full list is in Section 8 of the report and is part of the Licence Agreement. Results in these areas need independent checking.

  • Engine: EnergyPlus 9.4.0 only; its physics, numerical methods and known issues apply.
  • Geometry: flat roofs only; plenums and attics are not zones; a floor mixing zones with different multipliers is modelled once; zones taller than one storey get one storey; imported IDFs must use detailed surfaces.
  • Constructions and ground: Window5 data-file glazing, complex fenestration (BSDF), C-factor / F-factor constructions, fixed convection coefficients, two-dimensional ground models and skylights are not converted on import.
  • Loads and schedules: holidays of an imported IDF are not kept; gas equipment, refrigeration and exterior lighting are not converted.
  • HVAC: EnergyFront writes its own systems; components, curves, loops and controls of an imported IDF are not kept; equipment energy can differ substantially; HVAC equipment models are not validated against the HVAC BESTEST performance cases (CE300 and above).
  • Results: zone variables are not multiplied by zone or floor multipliers; central HVAC energy cannot be split by floor; Ideal loads report thermal energy converted with a constant COP on the Results page only.
  • Process: the report was prepared by the developer and has not yet been reviewed independently; no empirical validation against a measured building has been done yet.

7. Your responsibility

Before relying on any result, check it for your project: review the verification report of the run, the EnergyPlus error file (eplusout.err) and, for an opened IDF, the import report; compare with hand calculations, benchmarks, measured data or another simulation program; and have the results reviewed by a suitably qualified professional (Licence Agreement, Section 9). Do not describe EnergyFront or your results as certified, approved or validated by ASHRAE, or as compliant with ASHRAE Standard 140.

8. Public validation package

The public validation package (ZIP) lets you repeat the tests: the report (PDF), the results tables (CSV) of the Standard 140 cases, HVAC BESTEST, Furnace BESTEST and the example files, and the EnergyFront projects (*.json) of the Standard 140 cases. Open a project in EnergyFront, choose the weather file of the Standard (725650TYCST.epw, not included) and run it. The Standard, its weather file and the reference input files are not included.
