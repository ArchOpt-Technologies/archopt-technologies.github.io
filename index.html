EnergyPlus Calibration Software

EPCalibration is an EnergyPlus calibration software tool designed to support building energy model calibration using measured building data. It uses NSGA-II optimization and ASHRAE Guideline 14 performance metrics to identify calibrated building model parameters.

The software supports building simulation calibration, EnergyPlus model calibration, and evaluation using metrics such as CV(RMSE) and NMBE.
