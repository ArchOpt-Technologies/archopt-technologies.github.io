PareVia Building Design Optimization Software

PareVia is a building performance optimization software developed for EnergyPlus-based building energy simulation. It combines EnergyPlus simulation, XGBoost surrogate modelling, and NSGA-III multi-objective optimization to explore high-performance building designs.

The software can evaluate building energy use, embodied carbon, cost, and other performance objectives and identify Pareto-optimal building design solutions.

EPCalibration: Calibration Software for EnergyPlus Models

EPCalibration is a calibration tool for EnergyPlus models, designed to support building energy model calibration using measured building data. It uses NSGA-II optimization and ASHRAE Guideline 14 performance metrics to identify calibrated building model parameters.

The software supports building simulation calibration, EnergyPlus model calibration, and evaluation using metrics such as CV(RMSE) and NMBE.
